# Лабораторная №3. Вёрстка макета с помощью Flexbox и Grid

**Вариант 11**
**Тема:** Фотограф и визуальный сторителлер

## Цель работы

Освоить Flexbox для одномерных макетов и CSS Grid для двумерных, а также принципы адаптивной вёрстки.

## Описание

Одностраничный сайт-портфолио фотографа. Страница содержит информацию об авторе, его навыках, фотопроектах, настройках съёмки и форму обратной связи. Дизайн выполнен в серо-синей цветовой гамме с использованием CSS-переменных.

## Структура страницы

* **Шапка (`<header>`)**
  Имя и фамилия автора, заголовок страницы и аватар.

* **Основной контент (`<main>`)**

  * Секция **«Навыки»** — основные навыки фотографа.
  * Секция **«Проекты»** — четыре фотопроекта.
  * Секция **«Настройки»** — основные параметры съёмки.
  * **Форма обратной связи** — поля имени, Email, сообщения и кнопка отправки.

* **Боковая панель (`<aside>`)**
  Любимое направление — пейзажная фотография, а также ссылка на портфолио.

* **Подвал (`<footer>`)**
  Имя автора и год.

## Особенности CSS

В работе используются:

* CSS-переменные;
* Flexbox;
* CSS Grid;
* Media Queries для адаптивной вёрстки;
* псевдоклассы `:hover`, `:active`, `:focus`, `:visited`;
* эффекты масштабирования и изменения цвета изображений.

## Проверка DevTools

### 1. Проверка вёрстки

С помощью DevTools проверяется расположение основных блоков страницы, их размеры и соответствие макету.

### 2. Проверка Flexbox и Grid

В DevTools проверяется использование `display: flex` и `display: grid`, а также расположение элементов внутри соответствующих контейнеров.

### 3. Проверка адаптивности

С помощью режима адаптивного просмотра проверяется корректное отображение страницы при разных размерах экрана.

### 4. Проверка интерактивных элементов

Проверяется работа псевдоклассов `:hover`, `:active`, `:focus` и `:visited`, а также интерактивных эффектов для изображений и кнопки.

## Запуск

Откройте файл `index.html` в любом современном браузере.
